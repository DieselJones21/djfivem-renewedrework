# Envy Roleplay — Renewed Banking Rework

FiveM banking UI rework based on open-source [Renewed-Banking](https://github.com/Renewed-Scripts/Renewed-Banking).

Drop the `Renewed-Banking` folder into `resources/` and **do not rename it**. All existing scripts that call `exports['Renewed-Banking']` continue to work.

See [`Renewed-Banking/README.md`](Renewed-Banking/README.md) for install steps, exports, and UI notes.
